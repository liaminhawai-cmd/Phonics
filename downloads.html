Letter & Number Reversals Trainer

Drill for students who confuse letter and number reversals (b/d, p/q, 2/5, 6/9). Three modes: Write & Check with self-overlay, and Spot the Right One with hand/direction choices.

Features:
  • Canvas-based handwriting input
  • Self-check ghost overlay in VIC cursive
  • Direction-concept game (hands, arrows, spin)
  • Multiple fonts per round for shape learning
  • Progress tracking & session report

How to use your downloaded app

Option 1: Simply double-click the HTML file to open it in your browser.

Option 2: If that doesn't work, open your browser and drag the HTML file into it.

Using a local server (optional): For best compatibility, run a simple local web server:

python3 -m http.server 8000

Then open http://localhost:8000 in your browser.

No internet needed: These apps run entirely offline. Download once, use forever.
