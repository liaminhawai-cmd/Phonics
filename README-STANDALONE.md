# Downloadable Standalone Versions

Two fully self-contained HTML files for offline use or distribution.

## Files

### `phonics-standalone.html`
The complete **Aussie Phonics Trainer** in a single file.
- Year Levels (Pre–Yr 4, grouped by sound type)
- Bookmark Levels (14 colour-coded levels)
- Both practice modes: Look & Say + Listen & Write
- All HTML, CSS, and JavaScript embedded

### `mika-standalone.html`
**Mika's trilingual trainer** in a single file.
- Bookmark Levels only (no year view)
- Both practice modes: Look & Say + Listen & Write
- Trilingual: English, Mandarin (Hanyu Pinyin), Cantonese (Jyutping)
- All HTML, CSS, and JavaScript embedded

## How to Use

1. **Download** either file to your computer or device.
2. **Place the audio files** in the same folder:
   - `A.mp4`, `B.mp4`, `C.mp4` … `Ough.mp4` (70 MP4 audio files from the repo root)
3. **Open** the HTML file in any modern web browser (Chrome, Safari, Firefox, Edge, etc.).
4. **No internet required** once audio files are in place.

### Note on Audio
The app looks for audio files relative to the HTML file's location. If the audio files aren't present, the app will still work, but the "Listen to check" and "Play sound" buttons won't produce audio.

## For Offline Sharing

If you want to share the trainer with a group:
1. Create a folder (e.g., `Phonics-Trainer/`)
2. Put `phonics-standalone.html` (or `mika-standalone.html`) in it
3. Copy all 70 MP4 files into the same folder
4. Zip the entire folder and share
5. Recipients just extract and open the HTML file

## Remediation Links

The apps include links to:
- **Demo videos** (Google Drive links — requires internet)
- **Activity PDFs** (stored locally in the `activities/` folder — optional)

The demo video links will only work if the person has internet access and the original Drive folder is shared. To make the app fully offline, you can modify the app to remove those links or host the videos locally.
