# Spelling-sheet audio — file manifest

Each 'listen & write' sheet has TWO recordings (one per QR code on the printed
worksheet). Each recording reads the eight words for one set, in order.

The in-app **Spelling Sheets** activity looks for these files. **They're optional**
— without them the app reads the words with the browser's Australian voice. Add a
file and that sheet automatically upgrades to the real recording.

## How to add a recording
1. Open the Google-Drive link, download the audio.
2. Save it in this folder (`activities/audio/`) with the **exact filename** shown.
3. Commit it. That's it.

> Each PDF's two recordings are listed together. If you're unsure which Drive file is
> which set, open both and match by the first word — the app shows each word on-screen,
> so a mix-up is easy to spot and fix by swapping two filenames.
